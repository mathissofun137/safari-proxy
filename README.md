# Safari Proxy

Clean Safari-style browser shell. No sidebar, no games, no music player — just the browser UI.

## Live Demo

Open `index.html` or enable GitHub Pages on this repo.

## Features

- Traffic light window controls
- Back / Forward / Reload
- Safari-style address bar
- Start page with quick links
- Status bar

## Note

This is a front-end shell. For full proxy/unblocker behavior (service worker + Bare/Wisp), point the navigate function at a Scramjet or Ultraviolet endpoint.
